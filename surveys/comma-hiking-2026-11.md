1. 콤마하이킹 프로그램

- 이번 콤마하이킹에 전반적으로 얼마나 만족하셨나요? (1=매우 불만족, 2=불만족, 3=보통, 4=만족, 5=매우 만족)
- 콤마하이킹에 참여하게 된 이유는 무엇인가요? (복수) — 자연에서의 휴식 / 새로운 경험 / 하이커들과의 교류 / 하이킹 자체 / 호기심 / 기타
- 위에서 '기타'를 고르셨다면 이유를 적어 주세요
- 프로그램에 참여한 뒤 마음의 휴식이나 정서적인 환기를 경험하셨나요? (1=전혀 그렇지 않다, 2=그렇지 않다, 3=보통이다, 4=그렇다, 5=매우 그렇다)
- 프로그램에서 좋았던 부분을 알려 주세요 (자유)
- 프로그램에서 개선되면 더 좋을 부분을 알려 주세요 (자유)
- 참가비는 어느 정도가 적정하다고 생각하시나요? — 3만원 / 4만원 / 5만원 / 6만원 / 7만원 / 8만원 / 9만원 / 10만원
- 앞으로 1박 2일 프로그램이 생긴다면 추가되었으면 하는 아이디어가 있나요? (자유)
- 친구나 주변 사람에게 콤마하이킹을 추천할 의향이 있나요? (1=전혀 그렇지 않다, 2=그렇지 않다, 3=보통이다, 4=그렇다, 5=매우 그렇다)

2. 힐리힐리 앱 보물찾기 모험

- 앱으로 함께한 보물찾기 모험은 얼마나 재미있었나요? (1=전혀 재미없었다, 2=재미없었다, 3=보통이다, 4=재미있었다, 5=매우 재미있었다)
- 앱 지도를 보고 보물이 있는 곳까지 찾아가기는 어땠나요? (1=매우 어려웠다, 2=어려웠다, 3=보통이다, 4=쉬웠다, 5=매우 쉬웠다)
- 보물찾기에서 좋았던 점을 골라 주세요 (복수) — 지도를 보며 보물 찾아가기 / 보물 상자를 열 때의 두근거림 / 상품과 보상 / 일행과 함께 찾기 / 다른 사람이 찾은 보물 보기 / 기타
- 숨겨진 보물 개수는 어땠나요? — 너무 적었어요 / 적당했어요 / 너무 많았어요
- 보물찾기를 하면서 불편했거나 헷갈렸던 점이 있다면 알려 주세요 (자유)
- 다음 행사에도 보물찾기 모험이 있다면 참여하고 싶나요? (1=전혀 그렇지 않다, 2=그렇지 않다, 3=보통이다, 4=그렇다, 5=매우 그렇다)
- 보물찾기에 더해지면 좋을 아이디어가 있나요? (자유)
- 행사가 아닐 때도 산책이나 하이킹에 힐리힐리 앱을 쓸 생각이 있나요? (1=전혀 없다, 2=별로 없다, 3=보통이다, 4=쓸 것 같다, 5=꼭 쓰겠다)
